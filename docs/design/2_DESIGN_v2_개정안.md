## A. 움직임 (motion) — 바꿈

### A-1. 공용 스프링 토큰 추가 (원본 값 그대로)

| 토큰 | 강성 / 감쇠 | 쓰는 곳 (원본 설명) |
|---|---|---|
| `--spring-follow` | 900 / 50 | 손가락이 잡고 있는 것. 튕김 · 늦음 없음 |
| `--spring-settle` | 280 / 22 | 놓았을 때 · 값에 내려앉을 때. 작게 한 번 튕김 |
| `--spring-soft` | 260 / 24 | 큰 이동: 패널 · 시트 · 부품 전체 |
| `--spring-lead` | 620 / 36 | 늘어나는 선택 바탕: 움직이는 쪽 끝 |
| `--spring-trail` | 190 / 19 | 늘어나는 선택 바탕: 뒤따르는 끝(이것이 늘어남을 만듦) |
| `--spring-pop` | 520 / 16 | 고를 때 아이콘 · 숫자가 톡 |
| `--spring-fade` | 420 / 32 | 투명도 · 작은 밀림 |
| `--stagger` | 45ms | 여러 개가 차례로 들어올 때 간격 |

- 질량 1, `감쇠 = c`, `강성 = k` (원본 식 그대로).
- 모듈 고유 토큰은 그 모듈을 옮길 때만 추가하고 출처를 적습니다(예: `--hold-ms 1200` · `--deck-threshold 110` · `--pull-threshold 88`).
- 지금 토큰 `fast 120 · base 200 · slow 320ms · ease-out`은 **색 · 눌림 같은 CSS 전환용으로 남깁니다.** 위치 · 크기 움직임은 스프링으로.

### A-2. 공용 스프링 엔진 하나로 (`window.AQMotion`)

- `motion.js`의 뼈대를 앱으로: `S(x,k,c)` · `tune` · `step` · `clamp` · `spring('--토큰')` · `after(초, fn)` · `register(부품)`. 한 프레임을 4번 나눠 계산, 한 프레임 최대 1/30초.
- 앱에 맞게 바꿀 것: 사이트 전용인 테마 저장(`ms-theme`) · 느린 재생(slow-mo) · 부모 창 메시지는 뺍니다. 다 멈추면 rAF를 끄는 지금 `_npr` 방식은 남깁니다(배터리).
- 지금 따로 있는 것들을 이 하나로: 알림 `_npr`(이미 같은 식) · `_nis`(시간 · 튕김 → 강성 · 감쇠로 바꾼 식) · 종목 지도 펼침 카드 · 설정 Stack panel.
- 엔진 묶기는 화면이 바뀌지 않는 작업이라 시안 없이 `tools/ui-test`로 확인 후 반영하는 것을 제안합니다.

### A-3. 움직임 줄이기

- 원본: 움직임 줄이기 설정이면 감쇠를 `2√강성`(임계 감쇠)으로 — **움직이되 튕기지 않음.** `_npr`은 이미 이렇게 합니다.
- 지금 DESIGN.md: "움직임 없이 바로 바뀜".
- 제안: 스프링은 원본처럼 임계 감쇠, CSS 전환 · 흐림 · 저절로 도는 것은 즉시. ❓

### A-4. 길게 눌러 확정

- 원본 Hold to publish `--hold-ms 1200`, 앱 `.aq-hold` 800ms. 2단계에서 Hold to publish로 바꿀 때 1.2초로 바꿀지 ❓

## B. 원칙 6 — 바꿈

**지금**
> 6. 움직임은 이유가 있을 때만. 처음 들어올 때, 손으로 조작할 때. 출렁 · 번짐 · 젤리 · 오로라 · 커서 효과는 쓰지 않는다.

**개정안**
> 6. **움직임은 손과 상태를 따른다.** 처음 들어올 때 · 손으로 조작할 때 · 상태가 바뀔 때만 움직인다. 위치 · 크기는 공용 스프링으로, 가져온 움직임은 원본 값 그대로.
> - 쓴다: 스프링이 만드는 늘어남 · 튕김(젤리 슬라이더 · 늘어나는 선택 바탕 · 방울), 모양이 바뀌는 순간의 짧은 흐림(예: 알림 창 내용 흐림 5px → 0).
> - 쓰지 않는다: 손대지 않아도 저절로 반복하는 장식(오로라 · 구슬 · 물결 · 뒤섞이는 글자), 커서 따라오기 · 기울임(모바일), 숫자를 가리는 흐림, 터지는 입자.

- 이유: 알림 창(v8.56 · v8.62)에 이미 출렁(방울) · 흐림(5px)이 들어가 지금 원칙과 어긋나 있습니다. 개정안은 이것을 허용 범위로 정리합니다.
- 모듈표의 '안 씀' 판정(Weight wave · Goo morph · Scramble text · Siri orb · Magnetic button 등)은 이 개정안 기준입니다.

## C. 표면색 — 바꿈 ❓

| 단계 | 사이트(다크) | 앱 지금(다크) |
|---|---|---|
| 바탕 | `--stage #000` | `--bg #161618` |
| 카드 | `--card #171717` | `--panel #1c1c1f` |
| 부품 몸통 | `--surface #262626` | `--panel-2 · --bg-2 #222226` / 알림 창만 `#262626` |
| 채움 1 · 2 · 3 | 흰색 5% · 9% · 14% (칸 · 칩 · 막대) | 없음(`rgba(127,127,127,.16)` · `--bg-3 #2a2a2e` 섞어 씀) |
| 떠 있는 물체 | `--object #2c2c2c` | 없음 |
| 선 · 그림자 | 선 투명 · 그림자 0 | 선 투명(이미 같음) |

- 공통으로 제안: **채움 3단(`--fill-1/2/3`)과 `--object`를 추가**하고, 흩어진 `rgba(127,127,127,.16)` · `bg-3`을 여기로 모읍니다. 라이트는 원본처럼 어두운 색 4% · 7% · 12%를 앱 베이지 위에 씁니다. **그림자 0 · 선 없음**을 4장 '하지 않는 것'에 명시합니다.
- 바탕 · 카드 값은 둘 중 하나:
  - **가안 1 (사이트 단계 그대로):** 바탕 #000 · 카드 #171717 · 몸통 #262626. 알림 창과 같은 결이 됩니다. 앱 전체 인상이 크게 바뀝니다.
  - **가안 2 (앱 값 유지):** 바탕 #161618 · 카드 #1c1c1f · 몸통 #262626로 몸통만 맞춤.
- 강조색 · 오름 · 내림 · 글자색은 앱 것 그대로(사이트 초록 #34d17a · 빨강 #ff5a5f · 흰 알약 주 버튼은 가져오지 않음).
- 함께 고칠 것: `index.html` 안 다크 색 블록이 세 곳(183줄 `#1e1e1e`… → 4603줄 `#161618` → 9690줄 `#1c1c1f`…)에 겹쳐 있습니다. v2 반영 때 한 곳으로 모읍니다. DESIGN.md의 `panel-2 = panel-hi #222226`은 실제 코드(`--panel-hi #2a2a2e`)와 다릅니다.
