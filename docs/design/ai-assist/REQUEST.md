# AI 비서 — 서버 방 문의 (2026-11-28 · 디자인 방)

앱 우하단 단추(AI 비서 · `#aqAi`)를 이제 살리려고 해요. 지금은 누르면 「준비 중」 알림만 나와요.
**어떤 기능이 이미 있고, 어떤 것을 새로 만들어야 하는지** 알려 주세요. 답은 이 이슈의 댓글로 부탁해요.

## 0. 본부장님 말씀 (원문)

> AI비서의 주된 일은, AI매니저에서 결정할 것을 나한테 알려주거나 내 보유/관심 종목에 대한 주요 뉴스 업데이트, 향후에는 장마감 브리핑(오늘 지수는 왜 변동했는가? 내 보유/관심 종목은 왜 움직였는가? 그리고 클로드에서 자동으로 돌고 있는 '사건 조사' 등등이야. 자세한 내용은 서버 담당 통해서 정확하게 어떤 기능이 있는지, 혹은 앞으로 구축해야 하는지를 문의해봐도 좋아.

화면 방향: 별도 팝업 · 페이지 없이 우하단 단추가 그 자리에서 늘어나요. **먼저 알려주는 일**이 중심이고, 묻고 답하기는 나중이에요.

## 1. 디자인 방이 확인한 현재 상태 (틀렸으면 고쳐 주세요)

| 비서가 할 일 | 지금 앱에서 |
|---|---|
| ① 매니저에서 결정할 것 | `managerToday`의 `status = proposed` · `getFeed`의 매니저 제안 알림으로 읽을 수 있어 보여요 (미국만) |
| ② 보유 · 관심 주요 뉴스 | `leadGet {mode:'newsDay', mk, tickers}`로 종목 카드를 읽을 수 있어 보여요. 「주요」를 가르는 값은 모르겠어요 |

## 2. 답해 주세요

**① 결정할 것**
- 비서가 앱을 열 때와 몇 분마다 `managerToday`를 불러도 되나요? 건수 · 마감 시각만 주는 가벼운 길이 필요한가요?
- 매수 · 매도 제안 말고도 본부장님이 정해야 하는 것(AI가 묻는 것 · 이탈선 · 승인 대기 등)이 있나요? 어디서 읽나요?
- 마감 시각을 서버가 값으로 줄 수 있나요? (지금 앱은 00:00을 스스로 계산해요)

**② 보유 · 관심 뉴스**
- 카드에 중요도나 「새 소식」을 가릴 값이 있나요? 없으면 만들 수 있나요?
- 언제 새로 정리되나요? (미국 · 한국)
- 서버가 보유 · 관심으로 거른 것을 줄 수 있나요, 앱이 종목 목록을 보내는 지금 방식을 쓸까요?

**③ 사건 조사**
- 결과를 앱이 읽을 수 있게 해 줄 수 있나요? 필요한 값: 종목 · 종류 · 감지 시각 · 한 줄 · 원인 · 반영 · 앞으로 · 출처
- 얼마 동안 보관하나요? 「조사 중」 상태도 알 수 있나요?

**④ 장 마감 브리핑 (앞으로)**
- 지금 이 일을 하는 작업이 있나요?
- 새로 만든다면: 지수는 왜 움직였나 · 내 보유 · 관심은 왜 움직였나. 만들 수 있는 시각(미국 · 한국), 드는 한도 · 비용, 걸리는 시간은?
- 예전 브리핑 기능을 걷어낸 것과 부딪히지 않나요? 비서의 마감 브리핑을 새 기능으로 받을 수 있나요?

**⑤ 그 밖에 자동으로 도는 것**
- 비서가 알려 줄 만한 자동 작업의 목록을 주세요: 이름 · 도는 시각 · 결과가 쌓이는 곳 · 앱에서 읽을 수 있는지

**⑥ 알림 방식**
- 앱이 닫혀 있을 때 폰 알림(웹 푸시)이 있나요? 없으면 만들 수 있나요?
- 텔레그램으로 이미 보내는 것과 겹치는 것은 어떻게 할까요?
- 비서 항목을 기존 `getFeed`(종 알림)에 합칠까요, 따로 둘까요?

**⑦ 묻고 답하기 (나중 · 지금 만들지 않음)**
- 가능한 방식과 답까지 걸리는 시간, 계좌 값을 AI에 넘길 때의 규칙만 알려 주세요.

## 3. 디자인 방이 제안하는 모양 (바꿔도 돼요)

```
apiCall('assistFeed')  → { ok, at, items: [ {
  id, kind: 'decide' | 'news' | 'event' | 'brief',
  market, ticker,
  title,        // 한 줄
  body,         // 2~3줄
  at,           // 생긴 시각
  due,          // 결정할 것만: 마감 시각
  url,          // 원문 (있으면)
  read          // 읽었는지
} ] }
apiCall('assistSeen', { id })
```

- 관리자(본부장님)에게만 열어요.
- 가격이 급등 · 급락했다는 규칙형 알림은 비서에 넣지 않아요.
- 서버가 만드는 글은 짧게: 제목 한 줄, 본문 2~3줄.
