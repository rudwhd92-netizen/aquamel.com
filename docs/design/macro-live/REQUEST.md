앱이 받고 싶은 모양(이름 · 칸은 서버 방이 바꿔도 되고, 바꾸면 알려 주세요):

- 값의 시각은 **원천이 준 시각**(받은 시각이 아님). 앱이 「몇 시 값」을 표시하고, 지연 · 휴장을 이것으로 보여 줌.
- 못 받은 지표는 빼 주세요(앱은 종가를 그대로 보여 줌). 지어낸 값 · 옛 값을 새 시각으로 주지 않기.
- 사용자마다 받지 말고 **한 번 받아 모두에게**(약 60초 보관). 실패 · 요청 제한(yfinance rate limit)이면 뜸하게 다시, 직전 값 유지.
